# STUDYGO — TELA DE CURSOS

## Sistema sob nossa responsabilidade

- **Tela de Cursos** — tela responsável por exibir as informações de um curso específico.
- **Cursos Relacionados** — exibe outros cursos relacionados ao curso atual.
- **Informações da Escola** — direciona o usuário para a tela de empresas/escolas.


## Funcionamento

A tela de cursos será responsável por apresentar as principais informações
de um curso selecionado pelo usuário.

O usuário poderá visualizar:

- Nome do curso
- Ranking do curso
- Imagem do curso
- Categoria
- Carga horária
- Descrição
- Informações da escola
- Cursos relacionados


A tela seguirá a identidade visual do **StudyGo**, mantendo o padrão
visual definido para o projeto.
